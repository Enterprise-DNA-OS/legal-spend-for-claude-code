description: List line items that break the billing guidelines or the rate card.

Read CLAUDE.md. Run npm run spend -- guideline-breaches. Use --json when you need to work further with the rows. Never invent a figure that is not in the records.

RATE-ABOVE-CARD, TIMEKEEPER-NOT-ON-CARD, OUTSIDE-BILLING-PERIOD, DISALLOWED-EXPENSE and ARITHMETIC carry money at stake. BLOCK-BILLING, VAGUE-DESCRIPTION and DAILY-HOURS are queries to put to the firm. The guideline values live in settings.
