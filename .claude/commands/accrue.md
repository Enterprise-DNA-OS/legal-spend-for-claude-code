---
description: Record this month's estimate of unbilled work on a matter.
---

Read CLAUDE.md. Run npm run spend -- accrue <matter> --amount=N --basis="..." --actor=<name> [--period=YYYY-MM-01]. Use --json when you need to work further with the rows. Never invent a figure that is not in the records.

Confirm the record and values with the operator first. Every write needs --actor. Before update, decide or a second accrue on the same month, read show and pass --expected-version. If a name matches more than one record, list them and ask which one. The basis says where the number came from (the firm's email, the lawyer's estimate).
