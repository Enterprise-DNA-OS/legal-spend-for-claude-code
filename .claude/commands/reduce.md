description: Take an amount off one invoice line with a reason.
---

Read CLAUDE.md. Run npm run spend -- reduce <invoice> <line number> --amount=N --reason="..." --actor=<name>. Use --json when you need to work further with the rows. Never invent a figure that is not in the records.

Confirm the record and values with the operator first. Every write needs --actor. Before update, decide or a second accrue on the same month, read show and pass --expected-version. If a name matches more than one record, list them and ask which one. The reduction is before GST. Use --amount=0 to clear one.
